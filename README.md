# K—LAIDIAN

Kai 与来点设计工作室的网站设计预览。中文为主，英文辅助；冷黑、银灰与冰蓝，搭配微颗粒和金属渐层；首页以本地 Canvas 星光汇聚成字母 K，配合呼吸律动、星芒、指针视差和滚动渐退。

## 运行

需要 Node.js 20+，没有第三方运行依赖。

```sh
npm start
```

默认端口为 3000，也可运行 `PORT=3001 npm start`。`npm run check` 检查 JavaScript 语法。

## 页面

- `index.html`：单页主站，包含立体星光 K、滚动作品带、完整作品库及组合筛选、服务、品牌占位、介绍和联系。主导航为页内锚点；案例在当前页下方展开、切换及收起，不离开首页。
- `work.html`：统一的项目与作品库，可组合筛选归属、项目类型和设计类别；支持多标签与重置。
- `case.html?id=mozilla`：完整的第三方品牌案例研究，明确署名 Johnson Banks，包含概念、视觉、系统、应用、来源、相关作品。
- `case.html?id=inmotion`：包含本地 MP4 播放器的案例。

所有导航和素材使用相对路径，可部署在 GitHub Pages 项目子目录。未知案例 ID 有返回作品集的提示。

## 内容归属

Mozilla 是第三方品牌识别研究示例，不是 Kai 或工作室的商业项目。原设计机构为 Johnson Banks（2017）。本页视觉由本站构建，属于概念示意，不是原案例图片或交付物。原机构与 Mozilla 官方来源入口已经列出，但当前环境访问原机构网站被网络代理拒绝，未声称联网核验。

其他项目均为概念占位，不代表真实商业案例。合作品牌区域为虚构标志占位，并非真实合作背书。正式内容上线前需替换为真实项目、署名、案例资料和授权素材。

## 星光动画

Canvas 粒子在本地绘制，桌面 2200 个字母粒子、手机 1050 个。离开首屏或切换浏览器标签后暂停渲染；支持手动暂停、系统减少动态偏好及高分屏像素比上限。手机不启用指针交互。无外部动画依赖。CSS 以本地 `assets/grain.svg` 为少量区块添加微颗粒纹理。

## 空间与单页浏览

K 由具有前、后、侧表面的粒子体积构建，经偏航、俯仰和透视投影，并根据深度调整粒子的大小和亮度。背景有三层缓慢漂移的星云和远近星点。暂停与减少动态设置同时停止 K 与背景的变化。首页保留独立页作为兼容入口，但主浏览流程不跳转到它们。
